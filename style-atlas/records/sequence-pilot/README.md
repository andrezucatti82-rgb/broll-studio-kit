# Sequências para aprovação — piloto 1

36 exemplos em 18 categorias, com dois estilos existentes por categoria e quatro quadros por exemplo. Não são novos estilos: os IDs e o catálogo de 720 direções permanecem intactos. Página independente: `dist/sequencias.html`.

## Objetivo

Substituir a avaliação baseada em uma imagem isolada por uma sequência que apresente abertura, desenvolvimento, transformação e fechamento. O desenvolvimento funciona como quadro principal; os demais aparecem ao lado no desktop e em uma faixa deslizável no celular. A ficha permite ampliar todos os quatro quadros, registrar preferência e baixar observações. Os comentários ficam no navegador e não são enviados a um servidor.

O piloto inclui os dois exemplos de Interfaces, dados e sistemas e os dois de Motion Design de Campanha para avaliar a nova direção antes de alterar os 40 estilos de cada categoria. O usuário aprovou os 36 conceitos em 11/11/2026 e pediu uma proposta visual de interface com aparência de aplicativo antes da expansão aos estilos restantes. Não houve geração de vídeo nem aprovação automática.

## Procedência e reprodução

Todos os quadros são conceitos gerados pela ferramenta de imagens OpenAI para esta revisão. Pessoas, produtos, imóveis, interfaces e dados são fictícios. Os termos do provedor continuam aplicáveis. Não foram reutilizadas imagens de referência de terceiros.

`assets.json` registra prompt, hash da prancha de origem, dimensões, recortes geométricos e SHA256 dos arquivos WebP. As pranchas originais foram preservadas no ambiente de geração; não são necessárias para servir a página. Os 144 recortes individuais estão versionados. `build.py` documenta a separação e a construção dos dados da página, a partir dos jobs e registros locais de geração; não chama APIs nem consome créditos.

## Limites

- Quatro quadros não comprovam uma animação entre eles. Movimento, duração e mixagem permanecem sem teste.
- A tipografia nas imagens é uma indicação conceitual. O filme exige letreiros editáveis compostos em código e revisão de acentos e legibilidade.
- Produtos e personagens podem exigir quadros adicionais e estabilização de continuidade antes de animar. Para pessoas e produtos reais, os arquivos originais do cliente prevalecem sobre esta colagem.
- UI e dados devem ser reconstruídos em código ou capturados de sistemas autorizados. Os números das imagens não são uma fonte de dados de produção.
- O mapa fictício não representa localização, planta ou vizinhança real. Um anúncio de imóvel exige fontes e imagens verificáveis.
- Gostar do conceito não aprova moodboard, storyboard, amostra nem vídeo final de uma produção futura.

## Revisão

As 36 pranchas foram inspecionadas visualmente, com conferência de todos os quatro quadros em pranchas de contato e inspeção ampliada dos exemplos de Motion de Campanha, dados e infoprodutores. Legendas que não correspondiam ao resultado foram corrigidas. O exemplo Sankey recebeu uma segunda direção visual, com interface mais elaborada.

O catálogo completo foi auditado estruturalmente: 720 estilos, 714 referências visuais e seis amostras com revisão pendente. Nenhum registro possuía uma sequência de quadros. Isso não equivale a uma revisão visual individual dos 720 estilos.

O navegador conectado não estava disponível nesta sessão. A navegação, o gesto de deslizar, foco de teclado e enquadramentos em dispositivos reais permanecem sem verificação de navegador. Os mockups desktop/mobile são propostas visuais geradas, não screenshots de testes.
