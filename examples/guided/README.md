# Três percursos fictícios para validar a produção guiada

Estes presets preparam projetos; não contêm originais, vídeos, geração autorizada ou aprovações. A receita permanece planejada. As imagens do catálogo são somente referências conceituais.

Exemplo:

```sh
npm run plan -- --preset examples/guided/product-fictional-jewel.json --out projects/guided-product
```

Troque o arquivo para os casos de serviço e interface. O comando cria o coordenador, a ficha de fidelidade, o plano de pré-produção e os registros de estilo. Confira materiais e capacidades, apresente o preço atual e peça autorização antes de qualquer geração paga. Moodboard e storyboard exigem aprovações separadas antes da amostra.

Plano e estimativas históricas: [três testes](../../docs/three-recipe-tests.json). Não herdar orçamento ou autorização de outro projeto. Os clipes estimados não incluem locução, imagens, montagem, licenças ou tentativas extras.
